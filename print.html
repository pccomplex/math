🟢 المستوى الأساسي — بناء الفهم الأولي
تمرين 1.1: قانون التوزيع الموسّع
أكمل الجدول بتبسيط التعابير:
التعبير الأصليالتعبير المبسّط
(x+3)(x+4) 
(x−2)(x+5) 
(2x+1)(x−3) 
(x+6)(x−6) 
الحل:
(x+3)(x+4) = x² + 7x + 12
(x−2)(x+5) = x² + 3x − 10
(2x+1)(x−3) = 2x² − 5x − 3
(x+6)(x−6) = x² − 36 (فرق مربعين)

3x² + 6x = 3x( __ + __ )    5xy − 10y = 5y( __ − __ )    x³ − x² = x²( __ − __ )
الحل:
3x(x + 2)  ·  5y(x − 2)  ·  x²(x − 1)

🟠 المستوى المتوسط — التطبيق والربط
تمرين 2.1: معادلات تربيعية (التحقق بالتعويض)
ادّعت رنا أن حلول (x−4)(x+7)=0 هي x=4 أو x=−7.
أ. تحقّق بالتعويض.   ب. اشرح كيف حسبت الحلول.
الحل:
أ. x=4: (4−4)(4+7)=0 ✓  |  x=−7: (−11)·0=0 ✓
ب. حاصل الضرب = 0 إذا كان أحد العوامل = 0.
تمرين 2.2: كشف الأخطاء في اختصار الكسور
ما الناقص في اختصار (x²−4)/(x−2) = x+2 ؟
الحل:
الناقص هو مجال التعويض: x ≠ 2 (المقام لا يساوي صفرًا).
تمرين 2.3: صيغ الضرب المختصر — المطابقة
طابق كل تعبير بما يساويه:
العمود (أ)العمود (ب)
x² + 6x + 9(x−3)(x+3)
x² − 9(x+3)²
x² − 6x + 9(x−3)²
الحل:
x²+6x+9 = (x+3)²  ·  x²−9 = (x−3)(x+3)  ·  x²−6x+9 = (x−3)²
🟣 المستوى المتقدم — التفكير العكسي والإبداع
تمرين 3.1: التفكير العكسي — كتابة معادلة حسب الحلول
اكتب معادلة تربيعية لكل شرط:
الشرطمعادلة ممكنة
حلول: x=2 أو x=5 
حل واحد: x=−3 
لا حلول حقيقية 
حلّان حاصل ضربهما موجب 
حلّان حاصل ضربهما سالب 
الحل:
(x−2)(x−5)=0 ⇒ x²−7x+10=0
(x+3)²=0 ⇒ x²+6x+9=0
x²+1=0 (لا حلول حقيقية)
(x−2)(x−3)=0 ⇒ x²−5x+6=0 (2·3=6>0)
(x+2)(x−3)=0 ⇒ x²−x−6=0 (−2·3=−6<0)
تمرين 3.2: مسألة مساحة ومحيط
محيط مستطيل 34 سم وطول قطره 13 سم. احسب أطوال أضلاعه.
الحل:
نرمز للأضلاع x و y:
x + y = 17  |  x² + y² = 169
x² + (17−x)² = 169 ⇒ 2x² − 34x + 120 = 0
x² − 17x + 60 = 0 ⇒ (x−5)(x−12) = 0
الجواب: الأضلاع 5 سم و 12 سم.
تمرين 3.3: المتباينات — حل جبري وبياني
حلّ المتباينة (x−3)² > 4 بطريقتين.
الحل:
بيانيًا: القطع (x−3)² فوق y=4 عندما x<1 أو x>5.
جبريًا: |x−3| > 2 ⇒ x>5 أو x<1
الجواب: x ∈ (−∞, 1) ∪ (5, ∞)
