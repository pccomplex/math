🟢 المستوى الأساسي — بناء الفهم الأولي
تمرين 1.1: قانون التوزيع الموسّع (إكمال جدول)
أكمل الجدول التالي عن طريق تبسيط التعابير:
التعبير الأصليالتعبير المبسّط
(x+3)(x+4)
(x−2)(x+5)
(2x+1)(x−3)
(x+6)(x−6)
🔍 الحل المفصّل (اضغط)
(x+3)(x+4) = x² + 4x + 3x + 12 = x² + 7x + 12
(x−2)(x+5) = x² + 5x − 2x − 10 = x² + 3x − 10
(2x+1)(x−3) = 2x² − 6x + x − 3 = 2x² − 5x − 3
(x+6)(x−6) = x² − 36 (فرق مربعين)
تمرين 1.2: تحديد العامل المشترك
في كل تعبير، حدّد العامل المشترك قبل التحليل:
3x² + 6x = 3x( __ + __ )
5xy − 10y = 5y( __ − __ )
x³ − x² = x²( __ − __ )
🔍 الحل المفصّل
3x(x + 2)
5y(x − 2)
x²(x − 1)

🟠 المستوى المتوسط — التطبيق والربط
تمرين 2.1: معادلات تربيعية (التحقق بالتعويض)
ادّعت رنا أن حلول المعادلة (x−4)(x+7)=0 هي x=4 أو x=−7.
أ. تحقّق بالتعويض إن كانت رنا محقّة.
ب. اشرح كيف حسبت رنا الحلول.
🔍 الحل المفصّل
أ. التحقق:
x=4: (4−4)(4+7) = 0·11 = 0 ✓
x=−7: (−7−4)(−7+7) = (−11)·0 = 0 ✓
ب. استخدمت رنا القاعدة: حاصل الضرب يساوي صفرًا إذا وفقط إذا كان أحد العوامل على الأقل يساوي صفرًا.
تمرين 2.2: كشف الأخطاء في اختصار الكسور
حدّد الخطأ في كل مثال واشرح:
(x²−4)/(x−2) = (x−2)(x+2)/(x−2) = x+2 ❌
(3−x)/(x²−9) = −(x−3)/[(x−3)(x+3)] = −1/(x+3) ✅
السؤال: ما الناقص في المثال الأول؟
🔍 الحل المفصّل
الناقص هو مجال التعويض! في المثال الأول: x ≠ 2 (لأن المقام لا يمكن أن يساوي صفرًا). الاختصار صحيح فقط عندما x ≠ 2.
تمرين 2.3: صيغ الضرب المختصر — المطابقة والشرح
طابق كل تعبير في العمود (أ) بالتعبير المساوي له في العمود (ب):
العمود (أ)العمود (ب)
x² + 6x + 9(x−3)(x+3)
x² − 9(x+3)²
x² − 6x + 9(x−3)²
🔍 الحل المفصّل
x² + 6x + 9 = (x+3)² (مربع ثنائي حد)
x² − 9 = (x−3)(x+3) (فرق مربعين)
x² − 6x + 9 = (x−3)² (مربع ثنائي حد)
🟣 المستوى المتقدم — التفكير العكسي والإبداع
تمرين 3.1: التفكير العكسي — كتابة معادلة حسب الحلول
اكتب معادلة تربيعية لكل شرط:
الشرطمعادلة ممكنة
حلول: x=2 أو x=5
حل واحد: x=−3
لا حلول حقيقية
حلّان حاصل ضربهما موجب
حلّان حاصل ضربهما سالب
🔍 الحل المفصّل
(x−2)(x−5)=0 ⇒ x² − 7x + 10 = 0
(x+3)²=0 ⇒ x² + 6x + 9 = 0
x² + 1 = 0 (لكل x حقيقي: x²≥0 إذًا x²+1≥1≠0)
(x−2)(x−3)=0 ⇒ x² − 5x + 6 = 0 (الضرب: 2·3=6>0)
(x+2)(x−3)=0 ⇒ x² − x − 6 = 0 (الضرب: −2·3=−6<0)
تمرين 3.2: مسألة مساحة ومحيط (فضاء جبري)
محيط مستطيل 34 سم وطول قطره 13 سم. احسب أطوال أضلاعه.
🔍 الحل المفصّل
المرحلة 1: نرمز للأضلاع بـ x و y.
المحيط: 2(x + y) = 34 ⇒ x + y = 17
القطر (فيثاغورس): x² + y² = 13² = 169

المرحلة 2: نعوّض y = 17 − x:
x² + (17−x)² = 169
x² + 289 − 34x + x² = 169
2x² − 34x + 120 = 0
x² − 17x + 60 = 0

المرحلة 3: التحليل: (x−5)(x−12) = 0
الجواب: الأضلاع 5 سم و 12 سم.
تمرين 3.3: المتباينات — حل جبري وبياني
حلّ المتباينة (x−3)² > 4 بطريقتين:
أ. بيانيًا   ب. جبريًا
🔍 الحل المفصّل
أ. بيانيًا: القطع المكافئ (x−3)² يكون فوق الخط y=4 عندما x<1 أو x>5.

ب. جبريًا:
(x−3)² > 4 ⇒ |x−3| > 2
⇒ x−3 > 2   أو   x−3 < −2
⇒ x > 5   أو   x < 1
الجواب النهائي: x ∈ (−∞, 1) ∪ (5, ∞)
